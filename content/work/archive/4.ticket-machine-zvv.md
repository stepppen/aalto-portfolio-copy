title: ZVV ticket machine
outcome: A redesign of an outdated ticket machine interface.
year: "2023"
role: UX Research & UI Design
org: ZHdK
tier: archive
cover:
  src: /ZVV/thumb.webp
  alt: Redesigned ZVV ticket machine screen
team: Jeanne Antonin, Ege Seçgin, Elia Salerno, Stepan Vedunov
timeframe: "2023, university module"
status: Student project
context: |
  In a university module we redesigned the interface of Zurich's ZVV ticket machines. Over several design sprints we simplified complex flows, modernised the visual design, and added customisation and accessibility features.
myRole:
  - Heuristic evaluation, and a competitor analysis of ticket machines in several countries.
  - Led observations of people using the old machines in real situations.
  - Redesigned the full ticket-buying flow, with better accessibility.
  - Ran iterative user tests, ending with street tests of the final prototype.
results:
  text: In street tests, the final prototype did significantly better than the current machines across all user groups. People found it more accessible and easier to use.
